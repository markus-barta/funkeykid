Tastenbelegung

Lernmodus: Drück eine Taste auf der echten Tastatur. Sie leuchtet im Bild auf, wird ausgewählt, und du siehst, was sie sendet.

Tipp eine Taste im Bild an, um sie zu belegen. Mit dem Lernmodus wählst du sie durch Drücken auf der echten Tastatur.

Tastaturen

Eine Tastatur ist nur eine Liste von Tasten: Position, Beschriftung und welcher Code beim Drücken ankommt. Eingebaute Tastaturen sind fest; dupliziere eine, dann kannst du jede Taste neu beschriften und ihren Code festlegen (auch per Lernmodus). Jede Tastatur hat ihre eigene Belegung.
